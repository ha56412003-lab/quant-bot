### P4 · 策略加仓（观察期只统计机会，不实装）

**Q8. 让策略自己会加仓 —— 趋势再次确认才加，加多少由 ATR 算**

> 浩哥 2026-11-05 定：**这也是优化方向之一，记下来**。
> 当前状态：**未实装**。观察期只统计「如果允许加仓，会出现多少机会」。

**为什么不是手动加仓**

手动加仓会破坏整套风控的数学基础：现在每单最大亏损固定 50.65U，靠
`止损距离 × 数量 = 50.65U` 保证。手动加仓后止损价不变但数量变了，
单笔风险敞口直接翻倍，而系统内部的 `used` 还是按平均数算，**会低估真实风险**。

让策略自己加仓，才能把「什么时候加、加多少」写进规则、用回测验证。

**怎么做（三步，已摸清代码）**

第 1 步：放开策略里的闸门

```python
# 现在（strategies.py::S15CeZlsma.evaluate）
if ctx.has_position(sym, self.sid):
    continue                      # 有仓位就跳过，永远不加

# 改成
if ctx.has_position(sym, self.sid):
    pos = ctx.position(sym, self.sid)
    if pos.side == 信号方向 and 浮盈 > 0 and 再次站上ZLSMA:
        out.append(加仓信号)       # 同向 + 盈利 + 趋势再确认
    continue
```

「趋势再次确认」三个判据，**全是 S15 已算好的现成指标**：
| 判据 | 现成变量 | 加仓时要求 |
|---|---|---|
| CE 大方向没翻转 | `dirs == 1` | 必须仍是 1 |
| 再次站上 ZLSMA | `c > z and c > o` | 出现新的关键 K 线 |
| 信号新鲜度 | `fresh` | `fresh >= 2`（刚翻转的不算） |

第 2 步：加多少由 ATR 算（核心）

```
加仓数量 = (原仓当前浮盈 - 允许的新增风险) / 当前止损距离
```

例：入场 100、止损 97、数量 Q → 风险 3Q ≈ 50U。涨到 106，CE 止损棘轮到 103：
- 原仓浮盈 = (103−100)×Q = +3Q = **+50U**（已覆盖）
- 加 Q 数量，止损 103 → 新仓风险 = 3Q = 50U
- **净风险 = +50 − 50 = 0**（完全保本）

这就是金字塔加仓：**用已有浮盈覆盖新仓风险**，总风险不增，只放大利润。

第 3 步：回测验证（框架现成）

```bash
python -m backend.backtest run --sid S15_CE_ZLSMA --params '{"enable_add": true}'   # 实验组
python -m backend.backtest run --sid S15_CE_ZLSMA                                   # 对照组
```
对比：总收益 / 最大回撤 / 胜率 / 盈亏比。

**要补的代码（约 150 行，3 个文件）**
| 文件 | 改什么 |
|---|---|
| `backend/backtest/broker.py` | 加 `add_fill()`：按新价加数量、重算均价 |
| `backend/backtest/sim.py` | 识别「加仓信号」，区别于开新仓 |
| `backend/risk.py` | 放开「禁止加仓」，但加三道锁 |

**三道锁（缺一不可）**
1. **浮盈 > 0 才能加** —— 亏着的时候根本不允许（防马丁格尔）
2. **加仓后止损上移到保本以上** —— 最坏也是平手
3. **单币总量封顶** —— 名义价值 ≤ `余额 × 10% × 杠杆`

> ⚠ **最大陷阱**：金字塔加仓（赚钱时加）和摊平成本（亏钱时加）长得一模一样，
> 后者是绝大多数人爆仓的唯一原因 —— 在小亏上"赢"很多次，然后一次亏光。
> **第 1 道锁就是专门堵这个的。**

**观察期怎么统计（不实装也能测）**

每天扫一遍当前持仓，统计有多少个仓位满足「浮盈 > 0 + CE 方向未翻转 + 再次站上 ZLSMA」
—— 这就是「如果允许加仓，今天会出现几次机会」。

- 一周出现 ≥5 次 → 值得做，机会足够多
- 一周只有 1-2 次 → 做了也基本不触发，优先级降到最后

**注意**：这个是**改策略核心逻辑**，会污染观察期。所以最早也要 **11-12 观察期结束后**
才能动。现在只统计机会，不改代码。
