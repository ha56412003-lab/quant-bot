## 四、四个真坑（重点，别再踩）

### 坑 1 · `backdrop-filter: blur(14px)` 把底下的东西糊没了

浩哥说「透明不够 看不清底下点点和曲线」。第一反应是调 alpha，从 `.42` 调到 `.26` 再到 `.13`，**还是看不见**。

**根因不是 alpha，是模糊**：14px 的高斯模糊把底下的点阵和曲线**整个糊平了**，抹成一片均匀色块。这种情况下 alpha 调到 0 也看不见东西 —— 画面在进入浮框之前就已经被模糊掉了。

**正确做法**：先问「我要不要透」，要透就别上大模糊。最终取 **blur(2px)** —— 点阵虚一层、轮廓和走向还看得出来，数字完全不受影响。

### 坑 2 · `main.py` 没有 `import json` → `/api/radar` 的 reason 恒空

症状极其隐蔽：

- 库里 `detail` 字段完全正确 ✅
- 直接调 `radar.reason_of(detail)` 返回正确文案 ✅
- **但打接口返回的 `reason` 是空字符串** ❌

根因：`api_radar` 里 `json.loads(detail)` 抛 `NameError`（没有 `import json`），被内层 `except` 悄悄吞掉 → `det` 恒空 → `reason` 恒空。

**教训：只有造测试数据打真实接口才能暴露这类 bug。** 单元测试和直接调函数都验不出来。

### 坑 3 · MAC 两套主题空仓时挤在顶部

`:is(html:not([data-theme]), html[data-theme="paper"]) ... .stats[data-empty="1"]`
这个作用域**漏了 MAC** → `.stats` 锁 `flex: 0 0 420px`，雷达（`flex:1`）和五项小指标挤在 420px 内，剩下 236px 空白。

补 `html[data-theme="mac-dark"], html[data-theme="mac-light"]` 后四主题一致。

### 坑 4 · 三项数字三层都不接 mode

**浩哥原话：「今日实现 切实盘后 怎么还保留？」**

只有曲线（`/api/equity?mode=`）跟着切，浮框三个数一直是纸面口径：

| 层 | 问题 |
|---|---|
| `risk.daily_realized_pnl()` | 不接 mode，永远算当前运行模式 |
| `executor.equity()` | 不接 mode |
| `/api/status` | 不吃 mode 参数 |

**但 db 层早就支持了**（`closed_positions_today(day, mode)` / `open_positions(mode=)` 都有 mode 参数），只是上面三层没串下去。

修完实测：
