## 三、持仓卡片图标去重

### 问题

`avatarFor(sym)` 用哈希取模 `% 14`，10 张卡片从 14 个头像里随机撞 → 必然重复。

### 修法

```js
// 把所有持仓币种按字典序排序，第 k 个币种取 avatars[k]
function buildAvatarMap(positions) {
  const syms = [...new Set(positions.map(p => (p.symbol||'').replace('USDT','')))].sort()
  const map = {}
  syms.forEach((sym, k) => { map[sym] = avatars[k % avatars.length] })
  return map
}
```

- 同一币种永远同一个头像（不会因排序变化而跳）
- 持仓上限 10 < 头像总数 14 → **必定全不重复**
- 空卡用 `emptyAvatar(k, usedCount)` 取剩余头像，不与实卡撞脸

### 验证

10 张卡 → 10 个唯一 base64 图标，`是否全不重复: true` ✅

### 图标来源说明

参考站 `F:\agent-display\index.html` 里**没有静态图片**（`data:image` 出现 0 次）。
图标是运行时 `avatarURL()` 用 canvas 画出来的：

```js
function avatarURL(a) {
  const cv = document.createElement('canvas'); cv.width = 56; cv.height = 56
  const c = cv.getContext('2d'); c.scale(2, 2)
  if (a.shape === 'spider') drawSpiderIcon(c, 14, 14, 28)
  else drawBody(c, a, 14, 15, 9.5, {look: 0})
  return cv.toDataURL()
}
```

一共 14 个 agent（`CARD_ORDER = [0..13]`），已全部导出到 `frontend-v2/src/avatars.json`。

### 4.3 前端 React 导入清理（**踩坑**）

清了 23 个文件的 `import React from 'react'`（React 19 JSX 自动注入不需要）。

**结果白屏** —— 7 个文件用了 `React.useState` / `React.createContext` 等**显式调用**，删掉导入后运行时 `React is not defined`：

```

panels/FactorLibrary.jsx, panels/StatusBar.jsx, panels/StrategiesPanel.jsx
```

**修复**：给这 7 个文件补回 `import React from 'react'`。

**教训**：
> 判断 `React` 是否"未使用"不能只看 `React` 这个词出现次数 ——
> `.jsx` 里的 JSX 标签是编译期转换的，`React.xxx` 是运行时调用。
> 只要文件里有 `React.` 字面量，就必须保留导入。

## 七、给以后的自己

1. **删目录前查软链**：`ls -l <dir>` 看有没有 `->`，`find . -type l` 找所有符号链接。
2. **清 React 导入前查 `React.` 字面量**：`grep -rn "React\." src/` 命中的文件必须保留导入。
3. **改完必须浏览器实测**：build 通过 ≠ 页面能跑。这次 build 成功但整站白屏，是浏览器验证才发现的。
4. **破坏性操作前先 dry-run**：V1 删除前先 `cp` 到 F 盘并校验文件数，再 `rm`。
