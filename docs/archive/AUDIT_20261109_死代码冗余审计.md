## 七、顺带修掉的一个真 bug：影子系统数据一直是废的

`shadow.record(sig, px, stop, tp, acted)` 的 `tp` 直接取 `sig.take_profit`，而 S15 从 2026-11-06 起把 `take_profit` 写死 **0.0**。
`settle()` 里的判定是 `elif px >= tp` → 变成 `px >= 0` → **恒真**。

结果：`shadow_signals` 表 1208 行里有 **597 行 `outcome='tp'`**，全是「一进场就判触及止盈」的假数据。影子系统那段时间的「R1/R2/R3 哪套规则更好」的统计，因此完全不可信。

**已修**：签名改为 `record(sig, px, stop, acted)`，`tp` 内部按 2R 推算（`tp = stop + (px - stop) * 2`）。long 时 stop 在下、tp 在上，short 相反，天然对称。

⚠ **该表的历史 `outcome='tp'` 数据仍是脏的，不要拿来下结论。** 需要的话从某天起重新累积。
