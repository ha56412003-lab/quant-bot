**踩坑记录**

1. **`ddNear is not defined`** —— 删镜像三闸变量时漏了 `bar prog ${stopNear || ddNear ? ' near' : ''}` 这一处引用。
   `npm run build` 只做语法/类型粗检，**跑得过去**；页面是**运行时崩成白屏**。
   → 教训：前端删变量后必须**真开浏览器看 DOM**，`build` 通过 ≠ 页面能开。用
   `Page.addScriptToEvaluateOnNewDocument` 注入 `window.__errs` 收集器才能拿到 `ReferenceError`。
2. **汇总行 `关键K线 undefined/40`** —— `t('gate.summary')({...})` 少传 `key`/`eff` 两个字段。
3. **⑥EFF 列一律显示「关」** —— 门槛只在响应顶层给了 `eff_thr`，行内没有；前端读 `r.eff_thr || 0` → 0。
4. **`config.load_strategies()` 有副作用** —— 它顺手把 `config.UNIVERSE` 重置成候选池。
   `/api/gates` 每 2 秒被轮询一次，等于每 2 秒搅一遍内存里的大盘清单
   （表现：`tests/test_gates_verdict.py` 打桩的 UNIVERSE 被清成真实候选池 → 断言拿到 0 行）。
   → 改成 `_eff_signal_min()`：直接读 yaml + **按 mtime 缓存**，不碰 UNIVERSE。
