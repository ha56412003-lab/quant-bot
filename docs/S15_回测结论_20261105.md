## 一、策略规则（浩哥 2026-11-05 定稿）

### 固定不变量
| 项 | 值 |
|---|---|
| 图表 | Heikin Ashi（HA） |
| Chandelier Exit | ATR 周期 **1** × 倍数 **2.0** |
| 均线 | ZLSMA **50** |
| 止损 | 阶段性低点（20 根）下方 |

### 入场
1. CE 方向翻转（**事件**，不是持续状态）：由空转多 → 做多信号；由多转空 → 做空信号
2. 信号当根收盘价在 ZLSMA50 **同侧**（做多在上方 / 做空在下方）—— 反向的信号视为**无效，过滤掉**
3. **关键 K 线**：做多为「收盘在均线之上的阳线」，做空为「均线之下的阴线」
4. **成交方式**：挂单（maker），挂在信号 K 线收盘价，下一根回踩才成交
5. **ATR 门槛**：ATR / 收盘价 > **2.5%**
6. **震荡过滤**：布林带宽度(20,2) 处于近 **100 根**的**前 30%**（即百分位 > 70%）

### 出场（三条并列，谁先满足谁全平）
1. **止损**：碰到阶段性低点（20 根最低）→ 全平
2. **止盈**：涨到 **1.5R** → 全平落袋
3. **趋势反转**：收盘破 ZLSMA50 **且** 从持仓期最高浮盈回撤 ≥ **0.5R** → 全平

## 三、关键参数扫描记录

### 3.3 ADX 为什么被淘汰
- ADX 是**滞后**指标（14 根 = 3.5 小时），而策略平均持仓 7.6 小时 → 等 ADX 冲高时趋势已走大半
- 分档统计：ADX 30~40 区间**唯一亏钱**（胜率 33.3%，−4.10R）
- **ADX 「上升」的用法更差**：全部为负（−0.30 ~ −5.54R）
- ADX>25 表面上有用，实际只是「减少了交易次数」，不是「筛出了好信号」

## 五、发现的 Bug（已修复）

### ZLSMA 计算错误（s15_final.py）
**症状**：与 `s15_rules.py` 跑同配置差 13R（+19.53 vs +6.60）

**根因**：第二次线性回归时把序列中的 `None` 替换成 `0.0`
```python
# ❌ 错误写法
b = _linreg([x if x is not None else 0.0 for x in a], length)
```
前面的 `None` 全部变成 0 参与求和，导致 `b` 被拉低 → `a + (a-b)` 被放大。
实测 MAGMA 价格 0.25，算出 ZLSMA = 0.48（两倍偏差）。

**修复**：窗口内含 `None` 就跳过该根（符合 Pine `ta.linreg` 遇 na 返 na 的语义）
```python
def _linreg_series(src, length):
    for i in range(length - 1, n):
        seg = src[i-length+1:i+1]
        if any(x is None for x in seg):
            continue          # ← 跳过，不填 0
        ...
```

**验证**：
- 线性序列的回归右端点精确等于窗口末值 ✓
- None 正确传播 ✓
- 两个脚本修复后结果一致（差 0.39R，仅手续费舍入）

**影响**：结论变化很小（+19.72 → +19.10R），因为 ZLSMA 只用于判断「价格在上方/下方」，
值错了但相对位置大体保持。**但必须修，否则后续测试会踩坑。**

## 六、手续费的关键结论

- OKX USDT 永续 Lv1：**maker 0.02% / taker 0.05%**
- 完整回合 taker 0.1% + 滑点 0.03% ≈ **0.13%**
- 每笔费用(R) = 0.0013 ÷ 止损距离
- **盈亏平衡止损距离 = 4.28%**
- 本策略止损距离中位数 **7.75%** → 费用约 0.017R，可以承受
- **这就是为什么 ATR 门槛必须 ≥2.5%：ATR 太小时止损距离不足，手续费吃光利润**

### 时间止损为什么是 16 小时（不是 4 小时）

用户初版写的是 4 小时。实测：

| 6 小时 | 568 | 45.8% | +12.28 | −19.7 |
| 12 小时 | 556 | 44.6% | +16.24 | −22.8 |
| **16 小时** | 555 | 44.5% | **+21.71** | **−18.8** |
| 24 小时 | 551 | 43.0% | +17.73 | −18.3 |

4 小时版有 **322/578（56%）的单子被时间止损砍掉**，分币盈利只有 6/14。
原因：**平均持仓 6.93 小时、中位 4.50 小时** —— 4 小时正好砍在中位数上。
