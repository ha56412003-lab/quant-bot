## 一、这次改了什么

S15 此前只有三种出场：ATR×5 止损、1.5R 止盈、72 小时超时。

趋势跟踪策略没有「趋势结束」的出口，逻辑上是缺一块的 —— 趋势掉头了还拿着，
等于赌它随时回来。

新增第四种出场：

```
价格跌破 ZLSMA 且已有 ≥ 0.8R 浮盈 → 平仓
```

「≥ 0.8R 浮盈」这道门槛是关键。回测显示：不加门槛直接「一穿就走」，60 天
样本里触发 4891 次（占全部出场 95%），光手续费吃掉 274R，把 −37R 的结果恶化
成 −225R。加门槛后交易次数降到 637，胜率从 39.3% 提到 47.3%，回撤从 −62.7
砍到 −36.1。

参数 `exit_min_profit_r` 在 `strategies.yaml`，设 0 就关闭这个出场。

**判定标准**（事先定好，不许事后找理由）：

| 情况 | 含义 | 下一步 |
|---|---|---|
| 趋势出场 ≥ 3 笔，且这些笔的综合盈亏 > 0 | 门槛起作用了，提前落袋保住了利润 | 保持 |
| 趋势出场 ≥ 3 笔，但综合盈亏 < 0 | 提前跑反而错过后续行情 | 把门槛提到 1.2R 再看 |
| 趋势出场 < 3 笔 | 样本不足，无法判断 | 延长观察期，不动参数 |
| 出现报错 / 出场异常频繁（>20 笔） | 逻辑有 bug | 立刻停下来查 |

## 四、必须记住的前提

**回测里所有出场规则在 60 天样本上净 R 都是负的。**

最好的「浮盈 0.8R 出场」也只有 −11.46R / 637 笔 ≈ **−0.018R/笔**，基本是打平
偏亏。这意味着：

1. 这次补的不是「盈利圣杯」，是「逻辑完整性」
2. 这个策略在当前行情下期望值极薄，任何参数微调都可能把它推成明确亏损
3. 7 天后如果实盘也是打平偏亏，**该考虑的不是继续调出场，而是换周期或换策略**

诚实的结论比漂亮的数字重要。7 天后按数据说话，不按期望说话。
