# 风控提风险方案（单笔 0.5% → ?）

日期：2026-11-06
起因：浩哥「单笔亏损 0.5 有点低，容易被扫出局，给个修改方案」

---

## 一、先澄清两件被混在一起的事

**「单笔风险 0.5%」= 每笔最多亏多少钱，不是「止损设多近」。**

仓位大小和「会不会被扫出局」**没有关系** —— 止损被触发只看价格有没有碰到止损位，跟你下了多少手无关。

实测数据（20 币 / 60 天 / 2R 平一半）：

| 止损方式 | 净 R | 止损出场占比 | 止损距离中位 |
|---|---|---|---|
| **阶段低点（现状）** | **+38.22** | 31.9% | 1.60% |
| 前 30 根阶段低点 | +38.28 | 31.7% | 1.60% |
| 前 50 根阶段低点 | +35.81 | 32.4% | 1.64% |
| 1.5×ATR 兜底 | +34.93 | 32.1% | 1.60% |
| 2.0×ATR 兜底 | +32.67 | 32.8% | 1.73% |
| 3.0×ATR 兜底 | +35.44 | 36.8% | 2.19% |
| 4.0×ATR 兜底 | +10.31 | **46.0%** | 2.69% |

**结论：把止损放宽，不但没有降低被扫比例，反而在 4×ATR 时飙到 46%、净 R 掉到 +10.31。**
「阶段低点」已经是这套策略的最优止损方式，不要动。

**31.9% 的止损出场率，是趋势跟踪策略的正常水平**（约三分之一的单子是止损离场）。

## 二、真正的问题：日目标 200U 把收益锁死了

`daily_target.target_usd = 200`，**一达标就 `pause_new` + 自动全平 → 当天收工**。

回测实测（477 笔 / 63 个交易日）：

| 单笔风险 | 1R | 200U 等于几 R | 达标天数 | 达标率 | 因提前收工漏掉的 R |
|---|---|---|---|---|---|
| **0.5%（现状）** | 50U | 4.00R | 11 天 | 17% | **+68.5R** |
| 0.8% | 80U | 2.50R | 15 天 | 24% | +88.1R |
| 1.0% | 100U | 2.00R | 19 天 | **30%** | **+96.4R** |
| 1.5% | 150U | 1.33R | 24 天 | 38% | +110.2R |
| 2.0% | 200U | 1.00R | 25 天 | 40% | +118.3R |

**注意：提高单笔风险会让日目标更容易达标 → 提前收工的天数变多 → 反而丢更多机会。**

**所以提风险必须同时提高日目标，否则白提。**

## 三、三个联动项必须一起改

| 项 | 为什么必须跟着改 |
|---|---|
| `daily_loss_halt_pct` 3% | 单笔 1% 时，连亏 3 笔就触发全站停开 |
| `daily_target.target_usd` 200 | 不改的话 30% 的日子会在中午就收工 |
| 账户熔断线 9600U（−4%） | 单笔 1% 时连亏 9 笔就到，会被正常波动打断 |

## 四、三个方案

### 方案 A（推荐）

| 参数 | 现状 | **方案 A** |
|---|---|---|
| `risk_per_trade_pct` | 0.5 | **1.0** |
| `daily_loss_halt_pct` | 3.0 | **5.0** |
| `daily_target.target_usd` | 200 | **500** |
| `max_concurrent_coins` | 8 | **6** |
| 账户熔断线 | 9600U | **9200U** |
| **1R** | 50U | **100U** |
| **60 天预期** | +1,912U | **+3,824U** |
| **最大回撤** | 12.9%（1,292U） | **25.8%（2,585U）** |
| 日目标达标率 | 17% | 17%（500U 时） |
| 日熔断容忍连亏 | 6 笔 | 5 笔 |

**为什么是 1% 而不是更高：**
- 凯利公式理论最优 5.57%，但实盘要打 1/5 折扣应对模型误差 → 约 1.1%
- 回撤 25.8% 已经是心理极限，再高会在半路叫停
- 回测最大回撤 25.8R，方案 A 下就是 2,585U，账户从 10,005 掉到 7,400

### 方案 B（激进）

| 参数 | 方案 B |
|---|---|
| `risk_per_trade_pct` | 1.5 |
| `daily_loss_halt_pct` | 7.0 |
| `daily_target.target_usd` | 800 |
| `max_concurrent_coins` | 5 |
| 账户熔断线 | 9000U |
| 1R | 150U |
| 60 天预期 | +5,736U |
| 最大回撤 | **38.8%（3,877U）** |

### 方案 C（保守）

| 参数 | 方案 C |
|---|---|
| `risk_per_trade_pct` | 0.8 |
| `daily_loss_halt_pct` | 4.0 |
| `daily_target.target_usd` | 400 |
| `max_concurrent_coins` | 7 |
| 账户熔断线 | 9400U |
| 1R | 80U |
| 60 天预期 | +3,059U |
| 最大回撤 | 20.7%（2,068U） |

## 五、推荐

**方案 A。** 理由：

1. 收益翻倍（1,912 → 3,824U / 60 天），回撤从 12.9% 到 25.8% —— 加密市场里 25% 回撤可接受
2. 1% 正好是凯利打 1/5 折扣的位置，不是拍脑袋
3. 方案 B 的 38.8% 回撤大概率会在半路被叫停，反而拿不到那 5,736U

## 六、执行后的观察期处理

**风险比例只改变「金额」，不改变「R」** —— 净 R 指标（+38.22R）和胜率完全不受影响。
所以观察期的 R 类验收标准仍然可比，只有净值曲线会变。

**建议**：本次改动生效时刻起重新计 7 天观察期（11-13 复盘），和 2R 平一半一起算。

## 七、风险提示

- 回测 477 笔、63 个交易日，样本不算厚；25.8R 这个回撤是事后的，实盘可能更深
- 方案 A 下账户最低可能到 7,400U，**浩哥要能接受这个数字再上**
- 如果中途想降回来，改回 0.5% 立即生效（`strategies.yaml` 每轮扫描重读）
