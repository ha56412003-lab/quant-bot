## 四条出场（按引擎判定顺序）

| # | 出场 | 触发条件 | 代码位置 | 参数 |
|---|---|---|---|---|
| 1 | **16 小时超时** | 持仓满 16 小时 | `engine.py:110` | `max_hold_hours: 16` |
|   | 　└ 豁免 | **平过半的仓位不受这条限制**（让利润放开跑） | `engine.py:115` | `half_closed=1` 即豁免 |
| 2 | **移动止损** | 从极值回撤 N 个 ATR | `engine.py:118` | ★**当前关闭**（策略不传 `trail_dist`） |
| 3 | **硬止损** | 价格碰到开仓时算好的止损价 | `engine.py:135` | `swing_lookback: 20` |
|   | 　└ 止损价 | 做多 = 前 20 根 15m 的**最低点**；做空 = 前 20 根的**最高点** | 开仓时算好落库 | |
| 4 | **固定止盈** | 到某个固定价位就平 | `engine.py:143` | ★**当前关闭**（`take_profit=0.0`） |
| 5 | **策略出场** | 见下面两小节 | `strategies.py` `check_exit` | |

> 顺序很重要：**硬止损永远优先于策略出场**。价格同时触发两者时，按止损走。

## 策略出场（`check_exit` 内部，两段）

### 第一段：2R 平一半

```
浮盈到 2R → 平掉 50%，剩一半继续跑
```

- 参数 `half_at_r: 2.0`
- 只在**当前浮盈**到 2R 时触发（不看历史峰顶）
- 平过一次就落库 `half_closed=1`，不会重复平
- 返回 `HALF:2.0R止盈(先平一半,剩一半放开跑)`

### 第二段：剩下那一半怎么走（`_mirror_exit`）

**先判 3R 全平，再判镜像出场。**

#### ① 3R 全平

```
平半之后又赚了 1R（即总浮盈到 3R）→ 剩下的全平
```

- 参数 `half_tp_r: 1.0`
- 计算方式：`cur_r - half_at_r >= half_tp_r`
- 返回 `半仓止盈(再赚1.0R → 现3.05R)`

> 注意：原来的 `half_dd_pct` / `half_dd_r`（半仓后按回撤止盈）**代码从来没实现过**，
> 只是写在 yaml 里没生效，2026-11-08 复盘时已从 yaml 删除。

#### ② 镜像出场（核心）

**跟开仓条件完全镜像。开仓靠什么信号进，就靠什么信号的相反面出。**

| 方向 | 条件 |
|---|---|
| **做多出场** | ① CE 方向 **由多翻空**<br>② HA **阴线**（HA收 < HA开）**且** HA收 < ZLSMA50 |
| **做空出场** | ① CE 方向 **由空翻多**<br>② HA **阳线**（HA收 > HA开）**且** HA收 > ZLSMA50 |

**硬性要求：**
- 两条必须落在**同一根已收盘的 K 线**上（`i = len(ks) - 2`）
- 同一根 bar 只判一次（`_S15_MIRROR_STATE` 去重）
- **出场不加布林带条件**（见下）

#### 为什么出场不加布林带

入场第③道确实用了布林带分位（挤压结束才进），但**出场不加**。

线上口径实测（`use_close=true` + 6 仓约束）：

```
② 镜像+BBW  514 笔  +47.8R  −20.9  均持仓 43.4 根  ← 最差
⑦ 镜像无BBW 597 笔  +61.8R  −16.4  均持仓 26.5 根  ← 现在跑的
```

**带 BBW 看着笔数少，其实是把持仓从 26.5 根拖到 43.4 根。**
6 仓上限下，长期占仓直接挤掉后面的信号，反而少赚 14R。
**布林带在这里是拖延器，不是过滤器。**

## 完整参数表

```yaml
strategies:
  S15_CE_ZLSMA:
    max_hold_hours: 16          # 时间止损（平半豁免）

    params:
      # ── 入场（本轮未改）──
      ce_len: 1                 # CE 用 1 根 ATR
      ce_mult: 2.0              # ATR 倍数
      zlsma_len: 50             # 零滞后均线周期
      use_close: True           # CE 极值用 HA 收盘价（★口径关键）
      use_ha: True              # 用 Heikin Ashi
      swing_lookback: 20        # 止损 = 前 20 根摆动高低点
      bbw_pct_min: 70.0         # ★入场第③道：布林带分位 > 70
      max_risk_pct: 30.0        # 止损距离上限（实测只拦 0.03%）
      min_atr_pct: 0            # 0 = 关闭
      kline_interval: 15m
      fee_rate: 0.0005          # 币安 VIP0 taker
      slip_pct: 0.0             # 0 = 不设滑点

      # ── 出场 ──
      half_at_r: 2.0            # 2R 平一半
      half_tp_r: 1.0            # 平半后再赚 1R → 3R 全平
      # 镜像出场无独立参数，全部复用入场那套（ce_len/ce_mult/zlsma_len/use_close/use_ha）
```

## 验证方式

```bash
# 单测 13 项（打桩指标，测边界）
python test_mirror_exit.py

# 终验 32 项（真数据 + 真调函数 + 参数链路）
python scripts/verify_exit_final.py
```

`scripts/verify_exit_final.py` 会做四件事：
1. 参数全链路：`yaml → 实例 → _p()` 逐个比对
2. 真实 K 线扫描：48480 根，统计四条路各自触发多少次，逐笔验算指标
3. 端到端：真调 `_mirror_exit()`，喂真数据，看返回文案
4. 死代码：确认旧出场零引用

**任何改动出场逻辑的提交，必须先跑这两个脚本全绿。**
