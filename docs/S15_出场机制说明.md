## 一、总览：出场检查每 0.5 秒跑一轮，按顺序问 6 个问题

引擎主循环对每个持仓每 0.5 秒执行一次出场检查。**顺序固定，先命中先出场，后面的不再检查。**

```
┌─ ① 持仓超过 16 小时？ ──────────────→ 平仓「达到最长持仓时限」
│     （但平过一半的仓位豁免）
├─ ② 策略指定时间出场？ ──────────────→ 平仓「策略时间出场」
├─ ③ 移动止损（trail_atr）？ ─────────→ 平仓「移动止损触发」
│     （S15 未启用这一条）
├─ ④ 碰到硬止损价？ ──────────────────→ 平仓「止损触发」
├─ ⑤ 碰到止盈价？ ────────────────────→ 平仓「止盈触发」
│     （S15 线上止盈价 = 0，等于关闭）
└─ ⑥ 策略自定义出场（S15 的核心）─────→ 见第三节
```

**关键点：③④⑤ 是"价格到了就平"的硬条件，⑥ 是"满足一串逻辑才平"的软条件。**

**S15 真正的出场全靠 ⑥ + ④，⑤ 是关掉的。**

## 二、四个号码的来历（持仓期间不变的量）

开仓那一刻就定死了，之后不改：

| 符号 | 含义 | 怎么算 | 举例 |
|---|---|---|---|
| `entry` | 开仓价 | 信号价 | 1.3608 |
| `stop` | 硬止损价 | 做多取前 20 根 15m 最低点<br>做空取前 20 根 15m 最高点 | 1.3337 |
| `risk` | 1 个 R 是多少价格 | `|entry − stop|` | 0.0271 |
| `cur_r` | 现在赚了几个 R | `(现价 − entry) × 方向 ÷ risk` | +0.52 |

**R 是这个系统的通用货币。** 赚 0.52R 的意思就是"赚到了当初愿意亏的那个金额的 52%"。

- 你的每笔风险 = 权益 × 1.5% ≈ 153U
- 所以 1R = 153U
- 赚 0.52R = 赚了 79U

**还有一个动态量：**

| 符号 | 含义 |
|---|---|
| `peak` | **持仓期间到过的最高 R**（峰顶）。只涨不跌，每抬高 0.05R 才写一次库（避免每 0.5 秒写盘） |

## 三、S15 的自定义出场（第 ⑥ 步）分两段，分界线是「峰顶到没到 2R」

这是整个设计的核心。**峰顶有没有到过 2R，走完全不同的规则。**

### 第一段：峰顶 < 2R（占绝大多数）

**触发条件，三条必须全部满足：**

```
条件 1：收盘价跌破 ZLSMA50（做多）/ 站上（做空）
条件 2：这种情况连续出现 ≥ 5 根 15 分钟 K 线
条件 3：从峰顶回撤 ≥ 峰顶 × 50%（但最多不超过 0.8R）
```

**换算成能感受的时间：5 根 × 15 分钟 = 75 分钟。**

**回撤门槛 Examples：**

| 峰顶 | 回撤门槛 | 含义 |
|---|---|---|
| 0.3R | 0.15R | 赚 46U 时，回吐 23U 就走 |
| 0.5R | 0.25R | 赚 77U 时，回吐 38U 就走 |
| 1.0R | 0.5R | 赚 153U 时，回吐 77U 就走 |
| 1.9R | 0.8R（封顶） | 赚 291U 时，回吐 122U 就走 |

**所以这个设计的意图是：不锁定绝对利润，而是锁定"浮盈的一半"。赚得越多，允许回吐越多。**

### 第二段：峰顶 ≥ 2R（大赢家）

```
条件 1：收盘价跌破 ZLSMA50（做多）/ 站上（做空）
条件 2：这种情况连续出现 ≥ 2 根 15 分钟 K 线   ← 从 5 根降到 2 根
条件 3：从峰顶回撤 ≥ 0.8R                        ← 从比例改成固定值
```

**为什么第二段反而更灵敏（2 根）？因为已经赚够 2R 了，落袋优先。**
**为什么第二段回撤门槛更宽（0.8R 固定）？为了让大赢家放开跑，别被小波动吓走。**

### 半仓机制（独立的一条线）

```
到 2R → 平掉 50% 仓位，剩下 50% 继续跑
```

**平半之后，剩下一半有自己独立的三个规则：**

```
规则 a：峰顶从"平半那一刻"重新起算
规则 b：从新峰顶回撤 ≥ 0.8R → 全平
规则 c：剩下这一半又赚满 2R（即从 2R 到 4R）→ 全平
```

**这条是浩哥定的「2R 平一半，后面放开跑」。**

## 四、完整参数表（`strategies.yaml` 现状）

```yaml
# ─── 出场相关 ───
```

## 五、逐笔复核：昨晚 8 笔到底是怎么出去的

### 两笔硬止损（−153U 级别的满额亏损）

| | EVAA | ERA |
|---|---|---|
| 方向 | 做多 | 做多 |
| 开仓价 | 1.3608 | 0.0735612 |
| 止损价 | 1.3337 | 0.07152 |
| 止损距离 | **1.99%** | **2.77%** |
| 名义仓位 | 7,680U | 5,371U |
| 最大浮盈 | 0.52% | 0.17% |
| 峰顶 R | 0.22R | 0.05R |
| 结果 | −158.15U | −156.03U |
| 出场方式 | 价格直接打到止损价 | 同左 |

**这两笔根本没走到第 ⑥ 步。** 价格一路反向，碰到硬止损价就平了，止损逻辑正常执行。

**问题在入场，不在出场。** 它们从进场那刻起就没赚过（峰顶 0.22R / 0.05R），是"进场即错"。

### 五笔破均线回撤出场

| 币 | 峰顶 | 回撤门槛 | 实际回撤 | 确认根数 | 结果 |
|---|---|---|---|---|---|
| BEAMX | 0.38R | 0.19R | 0.19R | 5 根 | +28.00U |
| AIOT | 0.05R | 0.025R | 0.03R | 8 根 | +3.27U |
| SIGN | 0.31R | 0.155R | 0.49R | 5 根 | −26.56U |
| MEGA | 0.42R | 0.21R | 0.34R | 5 根 | +11.91U |
| BTW | 0.50R | 0.25R | 1.10R | 5 根 | −87.97U |

**看 BTW 这一行：门槛只要 0.25R，实际却回撤了 1.10R 才出场。**

**为什么拖了这么久？因为"连续 5 根破均线"这个条件先卡住了。** 价格在跌破均线后，中间只要有一根收盘拉回均线上方，计数就归零重来。

**这 5 根（75 分钟）里，浮盈从 +0.50R 一路滑到 −0.58R，没有任何保护。**

**SIGN 更极端：一度赚到 6.55%（0.31R），最后还亏 26.56U。**

**这就是"小赚大亏"的物理机制：回撤门槛没问题（0.25R 很紧），问题在"确认窗口"是 75 分钟，这 75 分钟是真空区。**

## 七、一句话总结

> **S15 的出场是一套「峰顶不足 2R 时守住浮盈一半、满 2R 后放开跑」的分段系统。**
>
> **它在统计上工作正常（840 笔 +73.3R，靠 54 笔 ≥2R 的大赢家贡献 +144.8R）。**
>
> **"小赚大亏"不是参数错了，而是这个策略的形状：胜率 48%，大部分单子小赚小亏，靠少数大赢家拉正总账。**
>
> **昨晚正好是没赶上大赢家的一小段，而且是 8 笔全开在震荡市（趋势效率 0.01~0.39）。**
