## P0 · 真 bug（必须修）

### BUG-1 `executor.py:113` 引用未定义变量 `pos`，实盘开仓必崩

```python
# backend/executor.py:112-113   实盘分支内
fill = price
fee = fill * qty * _close_fee_rate(pos)   # ← pos 在这一层根本没有定义
```

**触发条件**：`mode() == "live"` 时开仓。
**为什么没暴露**：paper 模式走 `else` 分支（114-122 行），用 `sig.fee_rate` 算费，完全绕过这行。
**后果**：一旦切实盘，**第一笔开仓就 NameError 崩溃**，且崩溃发生在已经下单之后（104 行 `place_market_order` 已执行）——会造成「单已下但没记账」的孤儿仓。

**这一条从设计上就该在接实盘前修掉，属于第三批审计遗留项的实证。**

`pools.monitor` 下有三个配置项，代码**从未读取**：

| 配置项 | 当前值 | 实际情况 | 危害 |
|---|---|---|---|

**验证方法**（已实测）：


**修法二选一**：
- **A（推荐）**：让 `configure()` 真的读这三个，配置恢复可信
