## 0. 一句话概括

在 **15 分钟 K 线**上做**双向趋势跟随**：用 Chandelier Exit 的翻向来判定方向切换，
用 ZLSMA(50) 确认趋势站得稳，用布林带宽度分位过滤震荡市。方向用 **Heikin-Ashi
合成价**判断，下单和止损用**真实收盘价**计算。

---

## 1. 数据要求

| 项 | 要求 |
|---|---|
| 周期 | **15m**（唯一周期，不需要多周期拼接） |
| 字段 | `open / high / low / close`（原始价，非复权、非合成）+ `timestamp` |
| 交易对 | USDT 永续合约，**20 个主流币**（见 §7） |
| 预热 | 每根 K 线评估时，向回至少取 **260 根**（ZLSMA 50 需要两遍回归 + BBW 100 根分位 + 80 根缓冲） |
| 时间戳 | 用 bar 的**开盘时间**标识一根 K 线；判断只看 `i = len-2`（**最后一根已收盘**的 bar） |

> **关键**：绝不能拿"正在跳动中的最后一根 bar"出信号，否则回测会引入未来函数。
> 我们的实现固定取 `i = len(ks) - 2`。

## 2. 指标定义（照抄即可）

### 2.1 Heikin-Ashi 转换

```
ha_close[i] = (open[i] + high[i] + low[i] + close[i]) / 4
ha_open[0] = (open[0] + close[0]) / 2
ha_open[i] = (ha_open[i-1] + ha_close[i-1]) / 2      (i > 0)
ha_high[i] = max(high[i], ha_open[i], ha_close[i])
ha_low[i]  = min(low[i],  ha_open[i], ha_close[i])
```

**后续所有指标（ZLSMA、ATR、布林带宽度）的输入都用 HA 序列**，
不是原始序列。这一条不能省 —— 省了买卖点和 TradingView 上看到的对不上。

> 止损用的"20 根阶段低点"例外，必须用**原始 K 线**的真实 high/low（见 §4.2）。

### 2.2 ZLSMA（零延迟最小二乘均线），长度 50

```
l1 = ta.linreg(ha_close, 50, offset=0)    # 对收盘价做一遍线性回归，取末端值
l2 = ta.linreg(l1,       50, offset=0)    # 对 l1 再做一遍
zlsma = l1 + (l1 - l2)
```

其中 `ta.linreg(src, len, offset)` 是 Pine Script 语义：对最近 `len` 个值做
最小二乘直线拟合，返回**末端（offset=0）**的拟合值。等价公式：

```
slope     = (len*Σ(j*src[j]) - Σj * Σsrc[j]) / (len*Σ(j²) - (Σj)²)     j = 0..len-1
intercept = (Σsrc[j] - slope*Σj) / len
value     = slope * (len - 1 - offset) + intercept
```

### 2.3 Chandelier Exit（ce_len=1, ce_mult=2.0，用收盘价）

```
atr = ta.rma(TR, 1)
    TR[i] = max(high[i]-low[i], |high[i]-close[i-1]|, |low[i]-close[i-1]|)
    ta.rma 是 Wilder 平滑：首个值 = 前 len 个的简单平均，之后 acc = (acc*(len-1) + v) / len
    注意：ce_len = 1，所以 atr 就是 TR 本身（Wilder 平滑退化为原值）

hh = max(ha_close[i-1 .. i])        # ce_len=1 → 只有当前根
ll = min(ha_close[i-1 .. i])

long_stop[i]  = max(hh - ce_mult*atr[i], long_stop[i-1])    当 close[i-1] > long_stop[i-1]
                否则 hh - ce_mult*atr[i]
short_stop[i] = min(ll + ce_mult*atr[i], short_stop[i-1])   当 close[i-1] < short_stop[i-1]
                否则 ll + ce_mult*atr[i]
```

棘轮逻辑：**多头止损线只上移、空头止损线只下移**。

方向判定（有状态，会继承）：

```
if close[i] > short_stop[i-1]:  dir[i] = +1     # 站上空头止损线 → 转多
elif close[i] < long_stop[i-1]: dir[i] = -1     # 跌破多头止损线 → 转空
else:                            dir[i] = dir[i-1]
```

> ⚠ 这里的 `close` 是 **HA 收盘价**（因为我们 `use_ha=True`，指标域全部用 HA）。
> 这是最容易搞错的一处：我们实盘算方向用 HA，算钱用真实价。

### 2.4 布林带宽度分位（BBW percentile），20 周期 2 倍标准差

```
mid   = SMA(ha_close, 20)
sd    = STDEV(ha_close, 20)              # 总体标准差（分母 n，不是 n-1）
upper = mid + 2.0*sd
lower = mid - 2.0*sd
bbw   = (upper - lower) / mid * 100      # 百分比宽度

bbw_pct[i] = 过去 100 根（含当前）里，有多少比例的 bbw <= bbw[i]，×100
             样本少于 20 根时该值为 None（无效）
```

**这不是 BBW 的绝对值，是它的历史分位。** 阈值 70 的意思是
「当前波动扩张程度排在近 100 根的前 30%」。

## 3. 入场规则（三道光闸，必须全过）

在第 `i` 根（最后一根已收盘的 bar）上判断：

### 闸一 · CE 方向翻转（事件，不是状态）

```
dir[i] != dir[i-1]
```

**只在翻转那一根出信号。** 如果写成"当前方向为多"的状态判断，会每根都满足，
信号数量翻 7 倍，全是假信号。

### 闸二 · 关键 K 线（HA 形态同侧）

```
做多：ha_close[i] > zlsma[i]  AND  ha_close[i] > ha_open[i]     # 阳线站上均线
做空：ha_close[i] < zlsma[i]  AND  ha_close[i] < ha_open[i]     # 阴线跌破均线
```

### 闸三 · 布林带宽度分位 > 70

```
bbw_pct[i] is not None  AND  bbw_pct[i] >= 70.0
```

数据缺失（None）**一律算不通过**，不能当通过处理。

> **为什么这道闸不能去掉**：CE 在震荡市会频繁翻转，去掉 BBW 门槛回测从
> **+35.20R 掉到 −35.41R**。这是全场唯一没被证伪的趋势过滤器
> （ADX、ADX 上升、效率比在测试中全部失效）。

### 开仓价与止损

```
开仓价 entry = 真实 close[i]        ← 不是 HA 收盘价

做多：stop = min(原始 low[i-19 .. i])      # 前 20 根（含当前）真实最低
      risk = entry - stop
做空：stop = max(原始 high[i-19 .. i])     # 前 20 根（含当前）真实最高
      risk = stop - entry
```

**校验**：

- `risk <= 0` → 放弃这笔
- `risk / entry * 100 > 30.0%` → 止损太宽，放弃（仓位会被压到极小，多半是数据异常）

> **为什么开仓价必须用真实收盘价**：实测过一笔 LIT，HA 收盘 3.4170 而真实收盘
> 3.4530（差 2.11%），导致实际盈亏比从 1.20 劣化到 0.73、单笔风险从 0.5% 放大到 0.82%。

## 4. 出场规则（四条并列，谁先满足谁执行）

### 4.1 半仓止盈 · 浮盈达 2.0R

```
sign   = +1（多） / -1（空）
cur_r  = (当前价 - entry) * sign / risk
```

- `cur_r >= 2.0` 且**该仓位还没平过一半** → **平掉 50%**，剩 50% 继续持有
- 每笔只触发一次（记 `half_closed` 标记）
- 平完之后，这条规则对这个仓位永久失效

### 4.2 硬止损

价格触及 `stop` → 全平。这是唯一在**亏损状态下**退出的通道。

### 4.3 趋势反转出场（只对盈利仓生效）

```
条件 A：当前 bar 的 HA 收盘价 跌破（多）/ 升破（空） ZLSMA(50)
条件 B：连续 2 根 bar 都满足 A（ma_confirm_bars = 2）
条件 C：从持仓期最高浮盈位置回撤 >= 0.8R（trail_r = 0.8）
```

三条同时满足 → 全平。

- 「回撤」是相对**持仓期间达到过的最高浮盈**（峰顶），不是相对开仓价
- 峰顶按实时浮盈算高水位，**不包含**已平掉的那一半
- **已经平过一半的仓位，这条规则继续适用**（剩下一半照样靠它退出）
- **亏损时不触发这条** —— 亏损单交给硬止损。这是刻意的：亏损就跑会在
  大趋势启动前的正常回踩中被震出局

### 4.4 时间止损

持仓超过 **16 小时** → 全平。

已平过一半的仓位**豁免**时间止损（让它放开跑）。

## 5. 仓位与风控

单笔风险按 R 定义：

```
1R = 账户权益 × 1.5%
止损距离 pct = risk / entry
名义仓位（U）= 1R / 止损距离pct
```

**但受以下上限截断：**

| 约束 | 值 |
|---|---|
| 单笔风险 | 账户权益的 **1.5%** |
| 杠杆 | **6x** |
| 单币名义上限 | 账户权益 × **32%** × 6 ≈ 权益的 1.92 倍名义 |
| 并发持仓数 | **6** |
| 同向持仓数上限 | **6**（等于不限方向） |
| 日亏损熔断 | 当日亏损达权益 **10%** → 停止开新仓 |
| 日盈利目标 | 当日盈利达 **800 U** → 停止开新仓（已持仓不强制平） |

> **注意**：止损距离 < 约 0.78% 时，名义仓位会被单币上限截断，
> 实际风险低于 1.5%（实测可低到 0.96%）。这不是 bug，是设计。

| 项 | 值 |
|---|---|
| 手续费 | **0.02%（maker，单边）** |
| 滑点 | **0%** |

### 8.2 分行情（按 30 天趋势效率分类）

分类口径（对方可复现）：

```
窗口 2880 根 15m（30 天）
amp = (max(high) - min(low)) / min(low)
eff = |price_end / price_start - 1| / amp
```

> 震荡市大赚，基本可以断定方向判断或 BBW 过滤理解错了。

## 9. 复现时最容易犯的 6 个错

1. **用原始 close 算 ZLSMA**，而不是 HA close → 买卖点和我们对不上
2. **把 CE 翻转当成状态判断**（`dir == 1` 就开仓），而不是事件（`dir[i] != dir[i-1]`）
3. **用 BBW 绝对值**当门槛，而不是**历史分位** → 不同币波动率差几倍，绝对阈值没法通用
4. **用 HA 的 high/low 算止损** → HA 是合成价，实盘不可能在那个价位成交
5. **拿最后一根未收盘 bar 出信号** → 引入未来函数，回测虚高
6. **忘了 BBW 分位的数据缺失要算不通过**（当通过处理会多出一批假信号）
