### 为什么是这一刻

从 11-05 到 11-09，参数改了四轮以上，每次改完基线都不可比：

1. **11-05** —— 池子 ATR 口径调整
2. **11-06 15:39** —— 出场改成「2R 平一半」
3. **11-06 18:06** —— ATR 降到 0.40，池子从 5 个变 32 个（进出池规则彻底变了）
4. **11-08** —— 风控改成方案 Z（1.5% / 8 并发 / 6x / 32% / 日熔断 10%）
5. **11-09 上午** —— 落地两条闸（进场偏离 >0.5%、出场快速失败 4h·0.5R）
6. **11-09 上午** —— 监控池口径换成 EFF（96 根 15m），光闸面板口径改了三轮

**第 5、6 项改的是「哪些信号能成交」，直接改变样本分布，旧数据不能算。**
所以起点定在最后一次改完之后的整点。

### 技术实现（一处改，两处生效）

```python
# backend/config.py
SAMPLE_START_STR = os.environ.get("QB_SAMPLE_START", "2026-11-09 12:00")
SAMPLE_START     = _parse_sample_start(SAMPLE_START_STR)   # datetime | None
SAMPLE_START_TS  = SAMPLE_START.timestamp() if SAMPLE_START else None
```

| 消费方 | 用法 |
|---|---|
| `backend/db.py::shadow_stats()` | SQL 加 `AND ts >= SAMPLE_START_TS` |
| `scripts/observe_report.py` | `START = config.SAMPLE_START`，基线自动取 |

**改起点只改 `config.py` 一处**，不要再在脚本里写第二个日期（以前就是这么漂的）。

## 观察期内的纪律

### 不许改的

- **出场逻辑冻结**（2R 平半 / 3R 全平 / 镜像 / 16h / 硬止损 / 快速失败 4h·0.5R）
- **`ce_len = 1` 一字不动**
- **两条闸参数**（`min_dev_pct 0.5` / `quickfail_hours 4.0` / `quickfail_min_r 0.5`）
- **风控六参数**（1.5% / 8 / 6 / 6x / 32% / 10%）
- **池子五参数**（size 40 / eff_min 0.30 / stop_min_pct 1.0 / min_quote_vol 500万 / max_spike 8.0）

### 可以做的

- 修 bug（不改行为的那种）
- 加观测（日志、指标、面板字段）
- 改视觉（不影响交易决策的）

**任何「调参」类改动，都会让这段观察期作废，起点必须重设。**

| 指标 | 门槛 | 说明 |
