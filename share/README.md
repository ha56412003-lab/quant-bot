# S15 策略包

一套可独立使用的趋势跟踪策略，用于币安 USDT 本位永续合约。

## 里面有什么

| 文件 | 说明 |
|---|---|
| `S15_CE_ZLSMA.pine` | TradingView Pine v5 脚本，直接贴进 Pine 编辑器就能跑 |
| `S15_策略说明.md` | 完整策略文档：原理、参数、回测数据、已知弱点 |

## 快速上手

1. 打开 TradingView，选合约（如 `BINANCE:BTCUSDT.P`）
2. 周期切到 **15 分钟**
3. Pine 编辑器 → 粘贴 `S15_CE_ZLSMA.pine` 全部内容 → 添加到图表
4. 想调参数就在策略设置的「输入」标签里改

## 一句话讲清楚这套策略

**等三个条件同时成立才进场：方向刚翻（CE）、K 线站稳均线（HA + ZLSMA）、当下有波动（BBW 分位 > 70%）。
进场后四条出场规则并列，谁先满足谁平仓。**

## 最重要的一句话

**这套策略必须挂单（maker）成交。** 同一套规则，maker 0.02% 是 +8.02R，市价 taker 0.05% 是 −94.88R —— 光手续费口径就能把赚变成亏。
