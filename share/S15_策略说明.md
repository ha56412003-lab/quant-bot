# S15 · Chandelier Exit + ZLSMA 策略说明

**给朋友测试用的完整说明。** 直接复制 `.pine` 文件内容贴进 TradingView 的 Pine 编辑器就能跑。

---

## 一、策略是什么

一个**趋势跟踪**策略，特点是不猜顶不猜底，只在趋势明确时进场，用 ATR 控制风险。

两条腿合起来判断：

| 组件 | 作用 | 来源 |
|---|---|---|
| **Chandelier Exit（吊灯止损）** | 判断「现在是多头还是空头趋势」 | everget 原版公式 |
| **ZLSMA（零滞后均线）** | 判断「K 线有没有真的站上去」 | veryfid 原版公式 |

**为什么要两个**：单用吊灯止损，趋势翻转后还会持续给多头信号；单用均线，震荡市会被反复打脸。两个一起用，要求「趋势状态」和「K 线形态」同时成立。

---

## 二、入场规则（唯一的一套）

### 做多
```
① Chandelier Exit 处于多头状态（上一根 K 线）
② 上一根是「收盘价 > ZLSMA」且「收盘价 > 开盘价」的阳线
③ 当前没有持仓
→ 下一根 K 线开盘做多
```

### 做空
```
① Chandelier Exit 处于空头状态（上一根 K 线）
② 上一根是「收盘价 < ZLSMA」且「收盘价 < 开盘价」的阴线
③ 当前没有持仓
→ 下一根 K 线开盘做空
```

**关键细节**：所有判断都用 `[1]`（上一根已收完的 K 线），**不用未收盘的当前 K 线**。这样信号不会闪烁、不会重绘。

---

## 三、出场规则（两种模式）

| 模式 | 止损 | 止盈 | 适用 |
|---|---|---|---|
| **优化（默认）** | `开仓价 ∓ ATR × 5.0` | `开仓价 ± 止损距离 × 1.5` | 系统性、可回测、参数稳定 |
| **原版** | 上一根 K 线的最高/最低点 | 收盘价穿越 ZLSMA | 更早出场，但止盈靠形态 |

**为什么默认用优化版**：原版止盈条件是「收盘穿越 ZLSMA」，在强趋势里会让利润回吐一大截；ATR + R 倍数是有明确数学定义的，回测结果更稳。

## 四、参数表

| 参数 | 默认值 | 含义 | 调整建议 |
|---|---|---|---|
| `ceLen` | **22** | ATR 周期 / 极值窗口 | 越大越迟钝，越小越敏感 |
| `ceMult` | **3.0** | ATR 倍数（吊灯距离） | 越大止损越宽 |
| `useClose` | **true** | 用收盘价算极值 | 保持 true，和原版一致 |
| `zLen` | **50** | ZLSMA 长度 | **这是最关键参数**，见下方说明 |
| `slAtrMult` | **5.0** | 止损的 ATR 倍数 | 越大止损越宽、胜率升但单笔亏损变大 |
| `rrRatio` | **1.5** | 止盈 = 亏损 × 1.5 | 越大盈亏比高但胜率降 |
| `entryMode` | 状态（同原版） | 入场严格程度 | 「翻转当根」只在 CF 刚翻转时进，机会少很多 |
| `useTrend` | **false** | 是否用 EMA200 过滤 | 开启后只做顺势，震荡市表现更好 |
| `cooldown` | **0** | 平仓后冷却根数 | 设 2-3 可以避免频繁反手 |

### ⚠️ 关于 `zLen` 的重要提醒

这个策略对 `zLen` **极其敏感**。

- `zLen = 32`：信号较密集，震荡市噪声多
- `zLen = 50`：信号较少，趋势更明确 ← **本系统实际使用值**

建议你测试时**先跑 50，再跑 32 对比**，看哪个更适合你交易的品种周期。

## 五、和完整系统的差异（重要）

这个 `.pine` 是**单仓位验证版**，完整系统比它复杂得多，别拿它的回测结果当成实盘预期：

| 项 | 这个脚本 | 完整系统 |
|---|---|---|
| 同时持仓 | **1 个**（`pyramiding=0`） | **最多 8 个**（并发上限） |
| 币种范围 | 手动选一个品种 | **候选池 100 → 监控 30 → 持仓 8** |
| 仓位大小 | 固定 10% 权益 | 按每单风险 0.5% 动态算 |
| 过滤条件 | 无 | 成交额 ≥1000万、插针比 ≤4.0、ATR ≥0.6% |
| 风控 | 只有止损 | 7 道闸门 + 熔断线 + 事件静默 |
| 多空限制 | 无 | 单边最多 6 个 |
| 最大持仓时间 | 无 | 72 小时强制平仓 |

**所以**：这个脚本适合验证「策略逻辑对不对、参数怎么选」，不适合直接用来判断实盘收益。

## 六、怎么用

### TradingView 快速测试

1. 打开 TradingView，选一个品种（建议先用 BTCUSDT 永续，15 分钟周期）
2. 底部点「Pine 编辑器」
3. 全选清空，粘贴 `S15_CE_ZLSMA.pine` 的**全部内容**
4. 点「保存」→「添加到图表」
5. 看回测结果，右键图表可以调参数

### 参数怎么调

在图表左上角策略名字旁边有个齿轮图标，点开就能改。

**建议的测试顺序**：
1. 先用默认参数（zLen=50, slAtrMult=5.0, rrRatio=1.5）跑一个品种
2. 把 `zLen` 从 50 改成 32，看信号数量和胜率怎么变
3. 把 `rrRatio` 从 1.5 改到 2.0，看盈亏比变化
4. 打开 `useTrend`（EMA200 过滤），看震荡市是否改善

### 回测要注意的坑

1. **必须用「深度回测」的品种**：TradingView 免费版只有部分品种有深度历史，浅历史回测结论不可信
2. **手续费要设对**：脚本默认 0.05%（万分之五），实际币安合约 taker 是 0.04%、maker 是 0.02%。如果你的策略频繁开平，手续费影响很大
3. **滑点要设**：脚本默认 2 tick，小币种可能更大
4. **不要只看总收益率**：要看**最大回撤**和**盈亏比**，还要看是不是靠某一笔暴赚撑起来的

## 八、这套策略的已知弱点

诚实告诉你，别踩坑：

1. **震荡市会被反复止损** —— 趋势跟踪策略的通病，靠 EMA200 过滤能缓解但不能根治
2. **假突破无法完全避免** —— 「阳线站上 ZLSMA」不等于「会继续涨」
3. **参数是拟合出来的** —— 22/50/5.0/1.5 这组值是在历史数据上优化出来的，未来可能失效
4. **单仓位验证版不反映系统真实表现** —— 完整系统的收益主要来自「多币种分散」，不是单次交易

**建议**：先当成一个「入场时机的参考工具」，不要当成稳赚的信号源。
